# 模型排行过滤零用量

## 目标与范围

避免零 Token 的请求记录出现在模型用量排行中。覆盖下拉框、概览和 Token 看板各时间范围；不改变平台排行、Token 总量、采集、原始请求记录或持久化。

## 需求与验收

- **RANK-001**：按当前时间窗口和模型汇总后，只展示 Token 总量大于零的模型；全部为零时模型排行为空，正数模型占比按展示的正数总量计算。
- **RANK-002**：保留原始请求记录和扫描结果，零用量记录不增加 Token 总量；保留现有平台排行和其他统计。
- **RANK-003**：自动化覆盖混合正零用量、全部为零、今日及历史排行，安装版界面需独立验收。
