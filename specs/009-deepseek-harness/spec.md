# 目标与范围

将本机 DeepSeek Harness 会话中可核实的请求用量纳入 Token 看板，按工具、模型、时间归集。仅扫描 `~/.dsh/sessions`，不读取凭据、不请求网络、不估算缺失用量，不修改安装应用。

## 需求与验收

- **DSH-001**：只读取已核实的 v4 会话 `assistant/message` 事件顶层 usage，输入、输出均须明确；流式镜像不重复计算。
- **DSH-002**：同一会话仅选择上游规定的最高日志版本；不支持的版本及继承历史的 seeded 会话保守跳过，不猜测用量。
- **DSH-003**：使用事件时间和消息实际模型；重复消息 ID 在文件内只计一次，读取失败沿用最后成功缓存。
- **DSH-004**：压缩日志只读完整重算，重复刷新与缓存重载稳定；缺失、失败不当作新增零用量。

本地记录并不代表账户账单；不保证其他版本、辅助请求及已删除会话完整。客户端按本机安装的桌面应用归类，不能区分 CLI 创建的日志。
