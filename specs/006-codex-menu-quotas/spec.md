# Codex 状态栏双额度

## 目标与范围

在 Codex 官方额度槽位中，图标右侧上下显示剩余百分比，上行为 5 小时额度，下行为周额度。遵循 [设计规范](../../docs/DESIGN_SYSTEM.md)。2026-11-02 用户确认将原先的上下顺序调换，以与主面板一致。

## 需求与验收

- **MENU-001**：两个额度独立取现有数据，上 5 小时、下周额度；单项缺失显示 `--`，不得以另一项替代。
- **MENU-002**：保留现有加载、DeepSeek 路由、其他槽位、系统模板着色与点击行为；辅助功能分别说明两项额度及缺失状态。
- **MENU-003**：在真实安装应用确认两行顺序、数字和可读性；自动化覆盖独立数值和缺失情形。

不新增网络接口、改变额度计算、状态项身份、提醒、登录项或安装机制。生成设计图仅用于确认布局，真实尺寸以安装应用验收为准。
