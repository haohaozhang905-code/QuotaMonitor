# 导航与下拉框玻璃材质产品规范

## 用户问题与目标

下拉框目前呈纯白或纯黑实色，主面板导航与 macOS 当前材质语言脱节。用户希望下拉框能透出桌面并实时模糊，主面板导航拥有克制的液态玻璃质感，同时保持额度和 Token 数字清晰。

目标是在不改动信息、数据、导航行为及状态栏生命周期的前提下，仅保留下拉框与主面板侧栏的透明模糊效果；右侧顶部横条维持正文实色并提供窗口拖拽。

## 范围与非目标

- 范围：下拉框背景、主面板侧栏、右侧顶部拖拽区域，以及系统“减少透明度”设置下的降级。
- 非目标：改变数据口径与交互路径、改动状态栏创建、应用身份、安装和通知样式；内容画布、卡片、选中项、切换控件、开关、图表提示与提醒卡沿用原实色样式。
- 修订记录：2026-09-19 首版把「右侧数据内容保持不透明画布」与「数据卡片不玻璃化」列为非目标；实测导致切换控件与卡片的玻璃层只能折射纯白/纯黑底板，用户要求整体液态玻璃化，上述两条被本版本取代（superseded）。
- 修订记录：2026-09-20 用户认为整体液态玻璃视觉效果不理想，要求恢复原实色视觉，只保留下拉框、主面板侧栏和顶部导航条的透明模糊。2026-09-19 的 GLASS-003～005 扩展范围由本次修订取代（superseded）。

## 需求

### GLASS-001 下拉框

下拉框在浅色和深色外观中使用半透明系统材质，窗口后方桌面变化应能影响其模糊表面；承载视图不得重新绘制不透明白底或黑底，文字、额度风险色和按钮仍可辨认。材质必须选用能真实透出模糊桌面的浮层材质（popover 级），禁止使用视觉上趋于不透明的桌面衬底材质。

2026-09-21 补充：深色下拉框需要接近系统电池面板的前景层级。标题、主数字、平台名称和操作项使用近白主色；更新时间、标签、路由和占比使用清晰中灰；品牌图标维持原彩色。动态桌面不得让前景呈现整体变灰或被蒙层覆盖的观感，下拉框背景不得叠加固定纸色蒙层阻断桌面颜色。

### GLASS-002 主面板导航表面

侧栏从窗口后方取样。右侧顶部横条使用与正文完全一致的实色背景并保留底部分隔，按住横条可拖拽窗口；右侧内容从横条下方开始，画布与数据卡使用原实色样式。

2026-09-21 补充：侧栏需在浅色、深色外观中明显呈现系统材质的背景模糊与透明感；不可因固定主题色覆盖而退化为近似实色。深色侧栏的品牌文字、导航文字和图标均为纯白。右侧顶部横条不使用侧栏材质，避免与正文形成错误色块。

### GLASS-003 导航选中项与降级（2026-09-20 修订）

侧栏选中项使用原实色胶囊；开启“减少透明度”时，下拉框和主面板导航背景恢复实色，选中项仍须明显。

### GLASS-004 主面板切换控件（2026-09-20 废止）

原要求切换控件使用玻璃材质，现已废止。分段选择和设置开关恢复原实色与系统开关样式；禁用状态、键盘与辅助功能行为维持原有实现。

### GLASS-005 内容画布与卡片（2026-09-20 废止）

原要求内容画布、卡片和浮层整体玻璃化，现已废止。主面板画布、数据卡、加载占位块、设置分组卡、图表 tooltip 和提醒卡恢复原实色视觉；Credits 弹层保持系统原生样式。

## 状态与验收

加载、无数据、失败和过期时沿用现有文案与颜色。分别在浅色、深色、不同桌面背景、最小窗口及“减少透明度”下观察下拉框和主面板；确认只有下拉框与侧栏透出模糊背景，右侧顶部和正文保持同色实面。检查导航点击、切换控件、禁用状态、顶部窗口拖动、滚动、文字对比与圆角边缘。自动构建只能证明 API 与类型兼容，最终视觉需在真实应用中验收。

公共视觉规则见 [`docs/DESIGN_SYSTEM.md`](../../docs/DESIGN_SYSTEM.md)。
