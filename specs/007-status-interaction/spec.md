# 状态栏点击态与下拉动画

## 目标与范围

点击状态栏呈现系统点击态和弹出动画，再次点击或点击外部时收起。按用户后续确认，优先采用 Status Trio v1.8.0 的系统弹出机制，接受系统箭头或外框变化；保留现有下拉内容。不能改应用身份、登录项、数据口径或安装流程。用户后续授权替换安装以进行真实对照。

## 需求与验收

- **INTERACT-001**：状态栏按钮采用系统原生点击态，打开与关闭时显示与恢复正确，加载及数据更新时状态保持一致。
- **INTERACT-002**：使用系统 NSPopover 展开与收起；再次点击状态栏或点击外部均可关闭。系统减少动态效果时立即打开与关闭。
- **INTERACT-003**：快速重复点击不能遗留窗口、错误高亮或使旧关闭回调影响新窗口；下拉框动作仍能打开主面板及设置。
- **INTERACT-004**：保留下拉框内部内容；系统箭头及外框变化已获用户接受。去掉旧视图自带的背景、圆角和描边，避免与系统外框叠加；替代 QMV-001 中下拉框自行提供材质的实现。实际屏幕边缘、深浅外观、全屏和多屏体验需真实验证。

视觉规则见 [设计规范](../../docs/DESIGN_SYSTEM.md)。构建和测试不能代替真实运行和视觉验收。
