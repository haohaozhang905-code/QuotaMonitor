# 问号说明弹框一致性

## 目标与范围

修复概览缓存、Token 看板缓存与 Codex 重置次数三个问号入口的箭头接缝和展开动画，保留已有内容、字号、250 pt 宽度、锚定方向及点击查看流程。遵循 [设计规范](../../docs/DESIGN_SYSTEM.md)。同时只读扫描其余页面，独立记录发现和证据。

## 需求与验收

- HELP-001：正文与箭头由同一原生表面连续绘制，浅深色均无内外底色接缝。
- HELP-002：说明立即出现和关闭，不使用缩放、弹跳或位移动画；减少动态效果时同样无动画。
- HELP-003：保留点击切换、外部点击和 Escape 关闭；周期/页面切换和窗口关闭不能残留弹框；关闭后仍可从触发按钮继续键盘操作。问号点击区域统一至少 18×18 pt，保留中性键盘焦点提示。
- HELP-004：默认与最小窗口、中英文、三处入口独立检查；自动化与真实候选应用验收分开记录。

## 非目标

不改数据采集、缓存口径、排行 hover 规则、状态栏、应用身份、登录项或安装脚本；不安装替换、不提交推送。其余扫描发现未经确认不扩展修复。

## 异常状态

数据刷新时保留最新说明；触发视图被移除时同步关闭；尚未进入窗口时不展示离屏弹框。

## 用户复审修订（2026-11-09，实施前 accepted）

本节覆盖此前关于原生材质、中性点击/焦点底色及不安装的约束。

- HELP-001 修订：浅色使用近白实色，深色沿用主题浮层色；正文与箭头连续，无边框和阴影。问号无新增点击/焦点底色。
- HELP-005：排行静态辅助功能摘要同时包含名称、原 Token 用量、占比及缓存率；保留仅 hover 的鼠标交互，不新增行按钮或键盘聚焦。
- HELP-006：周期桶只筛选一次，指标共享汇总，排行按平台/模型单次分组；hover 状态局限于排行组件，悬停不触发父页面数据汇总。未知、过期和其他分组的原计算语义不变。
- HELP-007：未提供来源、无日志、未检测到、扫描中显示中性色与相应可读状态；权限、格式、过期显示警示，真实刷新失败才显示失败色；可用来源优先。
- HELP-008：自动化、构建与真实候选关键交互通过后，备份并替换 /Applications/QuotaMonitor.app，核对签名、二进制和安装版进程。用户最终审美验收由用户确认。授权不含提交或推送。
