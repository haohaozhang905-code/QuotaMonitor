# 当前不足与可改造方向

[返回 README](../README.md) · [提醒机制方案](REMINDER_PRODUCT_DESIGN.md) · [安装与排查](INSTALL.md) · [工具支持清单](DATA_SOURCES.md) · [定制与二次开发](CUSTOMIZATION.md)

当前优先满足个人 Mac 上的额度观察和本地用量回看，以下能力仍有边界。欢迎提交 Issue 或 Pull Request 参与改进。

## 安装分发

- Release 是否提供可安装附件以 GitHub Releases 当前页面为准；没有适配附件时，源码安装需要 Swift 6 工具链。
- 后续可完善正式签名、公证和干净环境安装验证。

## 覆盖与准确性

- 尚无覆盖全部工具版本的兼容性测试矩阵。
- 通用解析器不保证所有来源自动去重，部分大 JSON 和非标准字段可能跳过。

## 数据完整性

- 不支持完整的云端账单同步、跨设备汇总或多账号隔离。
- 没有日志就无法还原相应用量。

## 易用性

- 暂无逐个数据源的可视化目录配置与启停向导。
- 自定义目录依赖启动环境或代码调整。

## 真实环境验收

- 提醒规则、迁移和用户状态门控已有自动化覆盖，真实锁屏、熄屏、合盖外接屏和系统通知仍需持续验收。
- 下拉框与主面板侧栏的透明模糊已实现，减少透明度、复杂桌面、多系统版本和窗口拖拽仍需要完整视觉记录。
- 菜单栏验证受 Control Center 日志可见性限制，脚本结果仍需结合屏幕上的实际状态项判断。

## 可扩展能力

已实现并保持固定规则：Codex 5 小时 / 周额度 30% / 5% 双档提醒、两类额度按时 / 提前重置、每个已知到期时间的重置机会提前 24 小时提醒。同批 5 小时与周额度同时重置时只投递周额度提醒。提醒已由 `ReminderRuleCatalog` 集中声明，固定条件由共享执行器处理；自定义阈值与预算告警仍待开发。

以下能力可以继续开发，当前不作为内置功能提供：

- 提醒阈值、分项开关与静默时段自定义
- 应用内提醒历史与逐条已读
- CSV 导出
- 预算告警
- 自定义供应商余额接口

## 平台与维护

- SwiftUI / AppKit 实现面向 macOS；Windows / Linux 需要移植界面和系统集成。
- 接口与日志格式变化需要持续维护。

想增加工具、换界面或设计提醒？[定制与二次开发指南](CUSTOMIZATION.md)提供代码入口、验证方法和可直接交给 Agent 的改造需求示例。
