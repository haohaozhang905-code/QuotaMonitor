# Install QuotaMonitor

1. Download the latest `QuotaMonitor-x.y.z.dmg` from [GitHub Releases](https://github.com/MeowkingCP/QuotaMonitor/releases).
2. Open the DMG and drag QuotaMonitor into Applications.
3. Launch QuotaMonitor after signing in to Codex for the current macOS user.

QuotaMonitor lives in the menu bar. It shows the official remaining quota, or the DeepSeek balance when the active Codex route points to DeepSeek.

## Settings

- **Launch at login:** Open the main panel and enable Launch at Login.
- **Language:** Switch between Simplified Chinese and English from the main panel.
- **Refresh:** The app checks quota and local token sources about once a minute. A recently active local session can trigger a quicker token refresh.

## Uninstall

1. Disable Launch at Login in QuotaMonitor.
2. Quit QuotaMonitor from the menu bar.
3. Move QuotaMonitor from Applications to the Trash.
