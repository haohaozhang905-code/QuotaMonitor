这版视觉的取舍

用于下一步 SwiftUI 实现对照

先额度，后消耗

概览页第一屏先呈现三个平台还能使用的额度，再呈现今日 Token 消耗，符合监控场景的使用顺序。

一套卡片，两种内容

credits 平台用剩余数值和进度条；豆包工作用双窗口进度条，结构相同，语义不混淆。

状态有解释

正常、预警、上次数据、未连接分别表达不同事实，让刷新失败不会变成没有上下文的短横线。
