# QuotaMonitor 分类色板扩展方案（v2 · 已实施）

> 状态：**已审核通过并写入代码**（`PanelTheme.categoryPaletteExtended`）。v2 依据反馈强化了浅色模式的色彩辨识度（原 v1 浅色下偏黑白灰）。

## 设计原则

1. **同色系明度梯度**：5 色系（墨 / 陶 / 雾灰 / 烟灰 / 沙）各 5 档 = 25 色。同一色系内仅明度递变。
2. **低饱和、有辨识度**：雾灰系带灰蓝色相、烟灰系带灰紫蓝色相、沙系为暖卡其——浅色模式下柱子不再是纯黑白灰，但全部保持低饱和、无冲击。
3. **索引 0–4 语义稳定**：Codex=0（墨）、Claude=1（陶）、Claude Code=2（灰蓝）、WorkBuddy=3（灰紫蓝），全 App 三处（柱状图 / hover / 排行卡）共用。
4. **深浅两套**：浅色模式档 1 最深 → 档 5 最浅；深色模式档 1 最亮 → 档 5 最暗。深色下 Codex 保持羊皮纸白（既有验收不变）。

## 索引分配规则

- **知名平台固定索引**：Codex=0、Claude=1、Claude Code=2、WorkBuddy=3。
- **其余平台 / 模型**：稳定哈希 `FNV-1a % 25`，同一实体永远同一色。
- **其他 / 合并项**：专用 fallback 灰（`#8B877F` / `#A5A19A`），不进色板。
- **超过 25 个实体**：列表层合并为「其他」（现有逻辑已支持）。

## 使用位置（全 App 三处统一）

柱状图 / hover 数据标签 / 排行卡 / 下拉框（如需色点）均读取 `categoryPaletteExtended` 同一索引，保证同一平台或模型在任何位置同色。
