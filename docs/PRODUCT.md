# QuotaMonitor 产品总纲

> 状态：Active<br>
> 最近更新：2026-09-19<br>
> 用途：定义项目级产品边界，并为功能级 Spec 提供共同前提

## 1. 产品定位

QuotaMonitor 是一个 macOS 菜单栏应用，帮助同时使用多个 AI 编程工具的个人开发者快速查看额度、余额和本机 Token 使用情况。

用户首先需要回答三个问题：

1. 当前额度或余额还能否支持接下来的工作；
2. 今天及近期的 Token 使用量如何变化；
3. 是否出现需要立即关注的额度、余额或用量事件。

菜单栏和下拉框承担快速判断，主面板承担趋势分析、来源诊断和设置。

### 产品机制与定位边界

产品将服务端返回的额度或余额、以及本机日志记录的 Token 用量放在同一处查看，同时保留各自的来源、单位、时间范围和新鲜度。用户可以先快速判断当前状态，再进入主面板核对趋势和数据来源。

这是当前产品方案的描述。尚无系统性的竞品比较或用户研究证据，不能据此宣称功能独有、统计覆盖最全或能够替代服务商账单。

## 2. 核心用户与场景

### 核心用户

- 同时使用 Codex、Claude、WorkBuddy、Qoder 等工具的个人开发者；
- 希望在本机统一观察多个工具用量，又不愿上传完整会话或日志的用户；
- 需要辨别官方额度、共享余额和本地 Token 统计差异的高频 AI 工具用户。

### 核心场景

- 工作过程中从菜单栏、下拉框快速确认 Codex 、Claude 的剩余额度和今日消耗 Token 量；
- 打开主面板比较近几日趋势、平台和模型分布；
- 在额度、余额或 Token 达到固定风险条件时收到**提醒**；
- 数据异常时确认来源状态、更新时间和统计边界。

### 使用环境

- 应用运行在个人 macOS 工作环境中；用户通常已安装并使用相关 AI 工具，额度查询依赖相应服务的有效认证，本地 Token 统计依赖本机实际留存且可读取的结构化记录。
- 工作中通过菜单栏和下拉框做短时查看，需要分析变化或排查来源时再打开主面板；提醒用于提示达到固定条件的事件。
- 网络失败、工具未安装、日志未覆盖或上游格式变化都可能造成缺失或过期数据。跨设备、网页端和其他 macOS 用户的活动不保证进入本机统计；具体边界以[工具支持清单](DATA_SOURCES.md)为准。

## 3. 产品目标

- 降低在多个 AI 工具之间切换查看额度和用量的成本；
- 对不同来源的数据给出可解释的时间、单位、来源和新鲜度；
- 在重要状态变化时提供克制、可去重、可降级的提醒；
- 以本地只读采集和最小凭据访问保护用户隐私；
- 让新增来源、规则和页面能够沿稳定的架构与验收方式扩展。

## 4. 产品原则

1. **数据真实：** 不用文本长度、上下文上限或无法验证的字段推算、估算 Token、费用和额度。
2. **状态可解释：** 加载、可用、缺失、过期、失败和未连接分别表达。
3. **本地优先：** 本地日志只读采集；网络请求限于用户已使用服务的额度或余额查询。
4. **失败保守：** 失败结果不覆盖最后一次成功数据，也不产生新的提醒事实。
5. **快速判断：** 菜单栏和下拉框优先展示当前最需要关注的信息。
6. **验收分层：** 自动测试、应用运行和视觉体验分别记录证据。

## 5. 当前产品范围

- Codex 额度与重置时间；
- 已识别 DeepSeek 路由下的共享余额；
- 多个 AI 工具的本地 Token 聚合、趋势和分布；
- 数据源安装、健康和新鲜度诊断；
- 固定规则的额度、余额、重置机会和 Token 提醒；
- macOS 菜单栏、下拉框、主面板、设置和本地化；
- 本地构建、签名检查和发布准备。

具体支持范围与统计口径见 [工具支持清单](DATA_SOURCES.md)。

## 6. 当前非目标

- 还原没有本地日志或可靠接口的数据；
- 将 Credits、上下文窗口或金额自动换算为精确输入/输出 Token；
- 自动兑换额度、充值余额或切换模型路由；
- 完整云账单、跨设备同步和多账号合并；
- 服务端保存用户完整对话或本地日志；
- Windows、Linux 和移动端客户端；
- 将未在真实环境验证的代码适配描述为已支持。

## 7. 项目级成功标准

- 核心数字能够说明来源、范围、单位和更新时间；
- 缺失或失败状态不会被误读为正常或零；
- 关键提醒在对应窗口内只出现一次，权限不可用时仍有降级路径；
- 常见数据源变化不会导致长时间阻塞或破坏最后一次成功快照；
- 深浅色、中英文、菜单栏和主面板均具备独立验收记录；
- 功能级需求可以从 Spec 追踪到代码、测试和真实验收。

### 当前证据边界

- [工具支持清单](DATA_SOURCES.md)记录当前代码的数据入口、统计口径和已知覆盖限制；代码入口或解析测试通过，不等于所有工具版本都已在真实环境验证。
- [架构与改动边界](ARCHITECTURE.md)记录采集、展示、提醒和状态栏的实现责任；各功能的自动化结果、真实应用检查与待验事项以对应的 [Spec 验收记录](../specs/README.md)为准。
- 目前没有可用于证明用户规模、节省时间或相对竞品优势的研究数据。涉及这类效果的表述应在取得证据后再加入产品承诺。
